# 🌼 Día de las flores amarillas

Una página hecha con HTML, CSS y JavaScript puro (sin librerías) para el 21 de marzo.

- Un jardín que florece al abrir la página, con amanecer, polen y pétalos flotando.
- Toca cualquier parte del jardín (o el botón «Planta una flor») para plantar una flor nueva.
- Crea una dedicatoria y comparte el enlace: quien lo abra verá tu mensaje entre las flores.

## Archivos

| Archivo | Para qué sirve |
| --- | --- |
| `index.html` | Estructura y textos de la página |
| `style.css` | Colores, tipografías, diseño y animaciones |
| `script.js` | Dibuja las flores, el polen y genera el enlace de regalo |

## Cómo verla en tu computadora

Descarga los archivos en una misma carpeta y abre `index.html` con doble clic.

## Cómo personalizarla

- **Colores:** están al inicio de `style.css`, en `:root`.
- **Textos:** están en `index.html`.
- **Cantidad y tamaño de las flores:** función `sembrarJardin` en `script.js`.
